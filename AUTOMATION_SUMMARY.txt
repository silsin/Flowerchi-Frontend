🆘 TROUBLESHOOTING QUICK LINKS:

Issue: Port 3000 already in use
Solution: lsof -i :3000 (Mac/Linux) or netstat -ano | findstr :3000 (Windows)

Issue: Docker not installed
Solution: Visit https://www.docker.com/products/docker-desktop

Issue: Docker daemon not running
Solution: Start Docker Desktop (Windows/Mac) or sudo systemctl start docker (Linux)

Issue: PostgreSQL won't start
Solution: Check logs with: docker-compose logs db

Issue: Application not responding
Solution: Wait 2-3 minutes for first startup, then check: docker-compose logs app

Issue: Can't create admin account
Solution: Check browser console for errors, then view app logs

For more help: See detailed documentation files above
